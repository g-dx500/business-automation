# Power Platform

Power BIおよびPower Automateを活用した業務改善・データ可視化のサンプルです。

## Power Automateによるメール添付ファイルの自動保存

特定のキーワードを含むメールを対象に、添付ファイルをSharePointのフォルダに自動保存するクラウドフローを作成しました。

- メールの条件判定
- 添付ファイルの自動保存
- エラー発生時のメール通知

使用技術：Power Automate、Outlook、SharePoint Online

## Power BIによる売上データの可視化・分析
実際のオンライン小売取引データを用いて、売上分析ダッシュボードを作成しました。

- アジア・オセアニア地域の年間売上推移
- 国別・商品別の売上ランキング
- 国別売上構成比
- 売上高・販売数量などのKPI表示

使用技術：Power BI、SharePoint Online
