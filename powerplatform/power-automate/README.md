# Power Automateによるメール添付ファイルの自動保存

特定のキーワードを含むメールを対象に、添付ファイルをSharePointの指定フォルダへ自動保存するクラウドフローを作成。エラー発生時のメール通知処理も実装。

## 制作目的
Power Automateによるメール処理とファイル保存の自動化、およびエラー発生時の通知処理を学習するための自主制作。

## 処理内容
- 特定のキーワードを含むメールをトリガーとして処理
- メールの添付ファイルを取得
- SharePointの指定フォルダにファイルを保存
- Scopeを使用して処理を構成
- エラー情報を変数に格納し、処理結果を管理
- エラー発生時に通知メールを送信

## 使用ツール
Power Automate（クラウドフロー）、Outlook、SharePoint Online
